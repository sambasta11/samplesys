# Run this project in VS Code

A simple sample inventory system website built with TanStack Start, React and Tailwind CSS.

## Requirements

- Node.js 20 or newer (https://nodejs.org)
- VS Code (optional extensions: ESLint, Prettier)

## Steps

1. Open the unzipped folder in VS Code (File > Open Folder).
2. Open a terminal (Terminal > New Terminal) and install dependencies:

   ```
   npm install
   ```

3. Start the dev server:

   ```
   npm run dev
   ```

4. Open http://localhost:8080 in your browser.

## Notes

- The sample items are stored in memory on the page (src/routes/index.tsx) and reset on refresh — this is intentional, it is a demo.
- No database or API keys are needed; everything runs locally.
